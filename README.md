# lunar-gun-fractals

<img width="3840" height="2160" alt="Image" src="https://github.com/user-attachments/assets/4d77aa48-cd77-4ee8-a765-66904967e945" />

---


This is a basic barebones collection of scripts for rendering lunar gun fractals. These fractals arise from the elliptical restricted 3 body problem dynamics of the earth-moon orbital system.
By ejecting off some payload (of negligible mass compared to the two primary bodies) from a lunar massdriver, we can use a colourmap to track how it moves across space. By linking this colour to where the trajectory starts (ie the massdriver’s exit location on the lunar surface) we can build up these fractals as equirectangular projections of the lunar surface.
